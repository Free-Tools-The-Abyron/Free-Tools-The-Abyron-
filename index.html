ABOUT

Built to be simple.

This project is a static, GitHub-friendly website. It has no required backend, account system, analytics script or third-party API. Most tools use browser APIs directly.

Privacy noteLocal tools process files in your browser. Your hosting provider still receives the normal website request when you open the site.

Deployment

  1. Upload this folder to a GitHub repository.
  2. Open Settings → Pages.
  3. Select the main branch and root folder.
  4. Save and open the generated GitHub Pages URL.
